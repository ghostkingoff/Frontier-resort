# 季节光照与天气事件接口

## 光照参考

- 数据：`data/lighting_v2/season_environment.json`
- 参考地：新潟县南鱼沼市鱼沼汤泽山村，气象站 `54841`
- 四季均为 30 天，每季使用 8 个光照阶段：
  - 夜间
  - 黎明蓝调
  - 日出
  - 上午
  - 正午
  - 下午
  - 日落
  - 暮色蓝调
- 阶段边界按当天日出、正午、日落时间动态平移。
- 阶段颜色、能量、曝光、阴影浓度、阴影柔度和地表反弹光在阶段末尾平滑过渡。
- `bounce_color` / `bounce_energy` 作为阴影视区的地表反弹环境光参与材质照明。
- 当前为无月光预览阶段，四季夜间天空环境光和地表反弹光均压到 `0.002`；主要可见照明来自窗户、路灯及其局部反光。

## 天气事件目录

数据：`data/lighting_v2/weather_events.json`

支持四类事件：

- `rain`
- `snow`
- `fog`
- `cloud`

每类仅提供三个尺寸：

- `small`
- `medium`
- `large`

每个事件规格包含持续时间、光照倍率、云量或雾密度等接口字段。

当前已接入的视觉：

- 雨、雾按现有独立天气层渲染。
- 云事件驱动地面、建筑和角色的噪波云影。
- 雪仍只有事件接口，暂未接入视觉。

## 云事件接口

当前已实现云影与大云云隙光，包括：

- 世界坐标噪波采样。
- 浅云层与深层云影的连续过渡。
- 地面、建筑与角色统一采样同一张云影遮罩。
- 窗户、路灯和室内光不会被云影压暗。
- 大云事件叠加世界坐标云隙光，方向随太阳方向变化。
- 云隙光使用最终光斑亮度决定可见强度，并受太阳能量、曝光和阴天遮光对比影响。

当前不包含：

- 视口中的云本体。
- 建筑、角色和树木对云隙光的硬遮挡。
- 积水中的云反射。

保留的接口：

- `WorldWeather.trigger_weather_event("cloud", size, duration_hours)`
- `WorldWeather.get_active_weather_event("cloud")`
- `WorldWeather.clear_weather_event("cloud")`
- F10 小云、中云、大云触发按钮。
- 云事件持续时间输入与清除按钮。
- F10 三档云影的覆盖率、直射遮光和环境遮光滑杆。
- F10 大云光斑大小与光斑数量滑杆。
- F10 大云光柱总亮度滑杆。

云影直接在地面、建筑和角色材质中按世界坐标采样现有噪波纹理，并组合 3 个不同尺度和旋转方向的噪波层。该方式与水坑遮罩相同，不再使用屏幕坐标离屏云图，因此没有重复小块和镜头跟帧延迟。

云影移动方向每天从 `4` 个斜向中随机选择一个：东南、西南、西北、东北。速度跟随游戏倍速，暂停时冻结。

浅云层和深层云层在世界材质中连续计算。浅层决定柔和外缘，深层增加核心遮光，两者使用连续权重混合，避免深层边界突然出现。F1 中的 `15` 和 `16` 可分别查看浅层和深层结果。

三级云接口整体上移一档：

- 小云接口使用原中云的 `0.78` 覆盖量。
- 中云接口使用原大云的 `0.97` 覆盖量，并继承更高的直射和环境遮光倍率。
- 大云接口使用 `0.995` 覆盖量，形成反相极端效果：深层云覆盖几乎整个画面，只保留噪波最低的少量透光孔。

窗户、路灯和室内局部光不会被这层环境遮罩压暗。

大云云隙光由 `shaders/lighting_v2/god_rays.gdshader` 实现，渲染在 `CanvasLayer 9`：高于雨、雾和大气层，低于 HUD。材质按世界坐标读取与云影相同的光洞噪波，因此镜头平移和缩放时不会出现屏幕坐标延迟。

光柱使用 8 层顶对齐加法遮罩：

- 视口中间及以上最多保留 8 层。
- 视口最下方最多保留 1 层。
- 最终层数取“光斑亮度对应层数”和“光斑屏幕高度允许层数”的较小值。
- 每个像素沿远离太阳的投射方向步进采样云层透射率，累积光洞散射能量，不再沿方向复制独立光斑。
- 步进穿过云层时使用指数衰减，靠近光洞和视口底部平滑淡出。
- 光柱向太阳方向延伸至屏幕外，在光斑端和视口底部渐隐。
- 光柱宽度由实际光斑区域决定。

F10 的云影调参仅在本次运行有效，可分别覆盖小云、中云、大云的覆盖率、直射遮光和环境遮光，并单独调整大云光斑大小、光斑数量与光柱总亮度。面板支持打印当前数据到 `.tmp/cloud_shadow_tuning.json`、复制到剪贴板以及恢复默认。

## WorldWeather API

```gdscript
WorldWeather.weather_types()
WorldWeather.weather_sizes()
WorldWeather.weather_event_spec("rain", "small")
WorldWeather.all_weather_event_specs()
WorldWeather.season_event_weights("winter", "snow")

WorldWeather.trigger_weather_event("snow", "medium", 2.0)
WorldWeather.get_active_weather_event("snow")
WorldWeather.get_active_weather_events()
WorldWeather.get_weather_event_effects()

WorldWeather.clear_weather_event("snow")
WorldWeather.clear_weather_events()
```

事件持续时间使用游戏内小时。手动触发只更新事件状态和光照影响参数，不改变现有雨、雾的视觉层。
