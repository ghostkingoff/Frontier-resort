# 3D 阴影代理制作规范

## 坐标与单位

Godot 运行时阴影空间直接使用像素坐标。`CELL = 32`，代理根节点位置使用
`(x_px, 0, y_px)`。

Blender 到 Godot：

```text
Godot_X = Blender_X
Godot_Y = Blender_Z
Godot_Z = -Blender_Y
```

统一单位：

```text
1 Blender 单位 = 1 格 = 32 Godot 像素
统一缩放 = 32
轴心 = 脚底 / 地面中心 = (0, 0, 0)
```

建筑运行时根节点仍位于逻辑占地中心：

```text
Vector3(
    (cell_x + footprint_w * 0.5) * 32,
    0.0,
    (cell_y + footprint_d * 0.5) * 32)
```

代理不需要占满逻辑占地。代理水平包络应由建筑 wall 的实际半径决定，允许建筑
占地大于代理，但不能用逻辑占地反向拉宽代理。

## 已接入建筑

| 资产 ID | 真实包络 `X×Y px` | Godot AABB `X×Y×Z` | 统一缩放 |
| --- | --- | --- | --- |
| `lodge_ordinary` | `146 × 98.09375` | `146 × 82 × 98.09375` | `32` |
| `shop_general` | `176 × 118.25` | `176 × 119 × 118.25` | `32` |
| `shop_small` | `192 × 128` | `192 × 90 × 128` | `32` |

导出的 `shadow_proxy.json` 必须满足：

- `uniform_scale = 32`
- `footprint_px` 等于模型真实包络
- `pivot_px = [0, 0, 0]`
- `ground_y_px = 0`
- GLB 根节点不再额外缩放或旋转

## 导出

```powershell
& 'E:\blender\blender.exe' --background --factory-startup `
  --python tools/export_shadow_proxy_glb.py -- `
  --blend art/source/buildings/shop_small/ChaoShi1_3DShadowProxy_v2.blend `
  --output art/characters/buildings/shop_small/shadow_proxy.glb `
  --footprint 192 128 `
  --scale 32
```

`--footprint` 必须传模型真实像素包络，而不是建筑逻辑占地。`--scale 32`
会校验传入包络是否与 Blender 模型尺寸一致，不一致时直接拒绝导出。

导出后必须让 Godot 重新导入 GLB：

```powershell
& 'E:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe' `
  --headless --path . --import
```

## 回归约束

- `tools/import_lighting_assets.py` 会校验三栋正式建筑的代理包络和 `32×` 缩放。
- `tools/weather_event_check.tscn` 会校验代理元数据、真实 GLB AABB 和脚底高度。
- 仅修改 `shadow_proxy.json` 不算完成；必须同时替换 GLB 并执行 Godot 重新导入。
