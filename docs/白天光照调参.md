# 昼夜光照调参

## 运行时临时面板

- 调试运行游戏时按 `F10` 显示或隐藏。
- 面板提供白天/夜间曝光、路灯亮度与衰减、太阳直射、传统方向光、法线、高光、Occlusion、墙面投影等实时滑杆。
- 白天/夜间环境色、太阳正午色和传统方向光颜色使用色轮修改。
- “打印并复制当前数据”会复制 JSON 到剪贴板，并写入 `.tmp/lighting_debug_snapshot.json`。
- 面板不会修改正式配置文件；重新启动后恢复默认值。

## 最常改的文件

### `data/lighting_next.json`

控制太阳直射、曝光、法线和高光：

| 参数 | 当前值 | 作用 |
| --- | ---: | --- |
| `scene_exposure_day` | `1.00` | 白天最终全屏曝光；对整体亮度影响最大 |
| `scene_exposure_night` | `0.60` | 夜间最终全屏曝光 |
| `street_lamp.brightness` | `5.00` | 路灯光池亮度 |
| `street_lamp.falloff_power` | `0.80` | 路灯光池衰减；值越大，亮区越集中 |
| `sun.maximum_energy` | `0.02` | 新光照系统的太阳直射强度 |
| `sun.minimum_color` | `#f2b06c` | 日出和日落附近的太阳颜色 |
| `sun.noon_color` | `#f3e0c2` | 正午太阳颜色 |
| `sun.legacy_maximum_energy` | `0.31` | 玩家和传统 Sprite 接收的 2D 方向光强度 |
| `sun.legacy_dawn_color` | `#ff9e47` | 传统方向光的清晨/傍晚颜色 |
| `sun.legacy_day_color` | `#f3e0c2` | 传统方向光的白天颜色 |
| `surface.normal_strength` | `0.85` | 建筑、屋顶和路灯法线强度 |
| `surface.specular_strength` | `0.055` | 法线高光强度 |
| `surface.occlusion_direct_strength` | `0.34` | 直射光受 Occlusion 压暗的比例 |
| `surface.wall_shadow_strength` | `0.79` | 墙面动态投影强度 |

推荐优先调：

1. `sun.noon_color`：画面偏白时改成更暖的米色；想恢复中性可改成 `#fff1dc`。
2. `sun.maximum_energy`：喜欢更柔和的太阳就继续降低。
3. `scene_exposure_day`：最后再调整体亮度。
4. `surface.normal_strength`：法线起伏是否明显。
5. `surface.specular_strength`：屋顶、墙面是否出现纯白高光。

### `data/lighting.json`

控制 CanvasModulate 的白天环境色：

- `10.0` 和 `16.0` 两个关键帧必须同时修改，才能保持白天平台期不变化。
- 当前白天颜色是 `#707291`，夜间颜色是 `#4b5a83`。

## 时间参数

仍在 `data/lighting_next.json` 的 `sun` 中：

- `sunrise_hour`：太阳开始出现。
- `full_day_hour`：达到白天最强。
- `fade_start_hour`：开始变暗。
- `night_hour`：达到最暗。
- `shadow_start_hour`：投影开始淡入。
- `shadow_end_hour`：投影完全淡出。

## 法线资源

当前已启用法线的资源：

- 玩家 `art/characters/player/star2a/` 的 walk/idle Normal。
- 基础度假屋墙面和屋顶 Normal。
- 路灯墙面和屋顶 Normal。

其他角色或建筑如果没有 `*_n.png`，会继续使用普通颜色贴图。
