## 一、怎么运行

**用 Godot 编辑器（推荐）**

1. 打开 Godot 4.7
2. 导入项目 → 选择 `E:\godot\模拟经营类\project.godot`
3. 按 F5 运行（主场景已经设好，直接进游戏）

**用命令行**

```powershell
& "E:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe" --path "E:\godot\模拟经营类"
```

## 二、当前已实现

**主界面与存档**

- 游戏启动先进入标题界面：开场短动画（幕布淡出 + 场景缓慢推进 + 标题浮现），点任意位置可跳过
- 主菜单三项：**新游戏 / 读取存档 / 设置**
- 存档类似星露谷：3 个存档位，每个槽是一局独立的游戏；标题界面能看到每个槽的「第几天 / 资金 / 设施数 / 游玩时长」，可以覆盖或删除
- **每天 24 点结算时自动保存**到当前存档位；探索前会另存一个探索前存档点（`slot_N_explore.json`）
- 游戏内按 ESC 打开菜单：继续游戏 / 保存进度 / 回到主菜单
- 设置：主音量、音乐、音效、全屏；保存在 `user://settings.cfg`
- 主场景是 `scenes/title.tscn`，点新游戏或读档后切到 `scenes/main.tscn`
- 存档只保存游戏进度（天数、资金、建筑、仓库、属性…）；「一天多长」「倍速」这类设计参数不写进存档，读档时永远用当前版本的设定
- 自动化测试写到独立目录 `user://saves_test`，不会碰玩家存档

**时间与经营**

- 全天 24 小时连成一条时间轴：06:00 → 24:00 → 次日 06:00（24 小时 = 现实 24 分钟，即游戏内 1 小时 = 现实 1 分钟；白天夜里流速一致），空格暂停
- 倍速：1x / 2x / 4x，另有一个 **64x 测试档**（在顶部信息栏最右侧，正式发布前删掉）
- **一天只结算一次**：24 点自动暂停并结算（营业额、到访人数、口碑），自动存档；早上 6 点不再弹结算，夜里 0-6 点的收益会并到下一次 24 点一起算
- 结算时三个选择：休息一晚（自动结算夜间收益并直接跳到次日 6 点）、外出探索（同样自动结算，回来就是早上 6 点）、夜晚继续管理
- 夜晚继续管理：从 24 点顺着同一条时间轴走到次日 6 点，只有夜间店铺接客、客流量降到约 1/2.6
- F 键跳过：白天按 F 跳到 24 点结算（仍然可以选夜晚继续管理），夜里按 F 跳到次日 6 点结算
- 夜里顾客、员工、治疗都会正常推进（之前夜里会停住）
- 店铺有开业时间：普通店铺 06:00-24:00，边境酒吧 22:00-04:00（`data/buildings.json` 的 open_hour / close_hour）
- 选择休息或探索时，夜间营业的店铺会按估算自动结算一次收益
- 资金、天数、口碑、设施数量显示在顶部信息栏

**地面与通行**

- 地面分三种：普通草坪（默认，不可通行）、可行走草坪（可通行）、地砖（可通行）
- 顾客只走地砖和可行走草坪，按网格寻路（四方向，不穿建筑）
- 建造菜单最上方「地面」：铺地砖 3 金/格、铺可行走草坪 1 金/格、恢复普通草坪 1 金/格，按住左键可以连着刷
- 地面全部由玩家自己铺（没有自动铺路）：起始地图自带一条主路、一条支路和两条通往起始建筑的小路
- 连不上主路的店铺不会有客人，建造时会直接提示哪些店连不上；建筑面板里也会红字提示“客人过不来”
- 顾客从主路两端进场，沿小路走到店门口；因为要绕路，一个人来回比以前久，单位时间到访人数会少一些

**拆除建筑**

- 建造菜单顶部新增「拆除建筑」工具：点建筑选中（红色高亮并显示返还金额），再点一次确认拆除，ESC 取消
- 建筑面板底部也有「拆除建筑」按钮，同样需要点两次确认
- 返还**投入的一半**（建造成本 + 已花的升级费用）
- 展厅里展示的物资会退回仓库；店里的顾客 / 病人会被请出去；地基与铺好的地面保持不变

**度假村围墙与入口**

- 建造区四周有围墙（底边中间留出入口，正对主路与支路），墙体不可通行、也不能铺地面
- 入口内侧是「招待厅」（其他设施分类，可升级）：客人一进门先到这里落脚，能补一点心情
- 起始地图自带主路、支路和通到小木屋 / 烤肉店 / 招待厅的小路

**建造**

- 格子式建造（一格 32×32 像素），半透明预览，绿色可放 / 红色不可放
- 6 种建筑：小木屋、家庭度假屋、边境烤肉店、杂货铺、边境诊所、珍品展厅
- 扣钱、占地校验、与已有建筑冲突校验

**顾客**

- 逐个模拟的**住客**：带预算进场 → 招待厅办入住 → 度假屋分配房间 → 循环「挑设施 → 走过去 → 消费 / 回房休息」→ 预算见底或心情低于 25 → 回招待厅结账 → 离店
- 度假屋收入按住宿天数在**结账时**产生（最少 1 晚）；招待厅全天开放并显示累计办理入住次数
- 客人类型带 `max_nights`：边境居民 0 晚（当日往返）、游客 2、家庭 3、收藏家 2、富商 3、明星 5；预算 2,000 ~ 50,000g
- 一间度假屋同时只住 1 位客人；客人白天在外消费 / 闲逛，只有晚上回房休息
- 白天也偶尔（约 20% 概率）回房歇一会儿；夜里则一觉睡到早上 6 点
- 客人有约 1/3 概率在村里闲逛（随机找个可通行格子待一会儿），并且不会连续去同一家店
- 地图尺寸 **128×80 格（早期版本的 4 倍）**，横向主街 + 中央大道 + 各店门前小路
- 新档初始配置：**每种建筑各一栋**（招待厅、小木屋、家庭度假屋、烤肉店、杂货铺、酒吧、诊所、珍品展厅），全部已接通主街，进游戏就能测试所有系统
- 走路用四方向贴图：素材是「列 = 方向、行 = 走路帧」，程序按这个规则取帧
- **视角风格：开罗式正面视角**——NPC 始终正面朝镜头（只播走路帧，移动时带轻微小跳步），建筑用正面立面。等补上侧向素材后，把 `customer.gd` 里的 `FRONT_FACING_ONLY` 改成 `false` 就会恢复「按移动方向切换朝向」
- 6 种顾客类型（居民、游客、家庭、收藏家、富商、明星），各自有预算与偏好设施，高级顾客需要口碑解锁
- 消费金额受建筑等级、顾客预算、心情影响，消费时弹出金币数字
- 顾客在店里时进入建筑的内部视图，关闭屋顶即可看到

**画面**

- 屋顶开关（R 键）：开=只看外观，关=透视看到店内顾客
- **视角：正面视角（星露谷式）**——建筑用整张正面贴图铺满占地，关掉屋顶（透视模式）后只显示室内
- 备用方案：`building.gd` 里保留了 `THREE_QUARTER_VIEW` 开关，改成 `true` 会切换成"正面贴图 + 梯形屋顶 + 右侧墙"的 3/4 玩具屋造型（屋顶用分类色占位），当前默认关闭
- 相机：WASD 平移、滚轮缩放、鼠标中/右键拖拽、触摸拖动与双指缩放
- 中文像素字体（方舟像素字体，OFL 授权）
- 世界光照按小时变化：00:00 深夜 → 03:30 凌晨最暗 → 05:00 泛白 → 06:00 日出前的红 → 07:00 清晨暖光 → 正午中性 → 傍晚转橙 → 深夜转蓝；界面亮度不受影响，关键帧在 `data/lighting.json`

## 三、Phase 2 已完成（经营深度）

**员工**

- 每栋建筑可以雇佣 / 解雇员工，工资固定（按建筑类型，日结）
- 员工有状态值，客流量越大掉得越快；每天开盘前休息恢复
- 员工全部状态过低（或一个人都没雇）→ 客人消费后心情下降，消费变少
- 医院可以花钱请更好的医生：治疗更快、同时接诊更多病人

**建筑升级**

- 点建筑打开面板，可看到升级所需资金与探索物资
- 升级后容量、平均消费、心情加成提升；医院还能治疗更多病症
- 探索物资不足时，按钮会直接写明缺少什么

**医院与病症**

- 6 种病症，分 1~3 级；诊所等级决定能治哪些病（1 级治不了跌伤与边境热）
- 客人生病后会走向能治病的诊所排队、接受治疗并付诊费，口碑上升
- 半天（游戏内 6 小时）内得不到治疗就会离开，口碑下降

**珍品展厅**

- 有展示位上限（随等级提升），玩家自己决定展示哪些物资、各多少件
- 展示的物资按稀有度累计“吸引力”，越多越容易吸引收藏家、富商与明星
- 每天结算时随机成交，成交价高于倾销价，口碑也会上升

**内陆倾销**

- 仓库面板里可以按 35% 价格把滞销物资卖给内陆商人（单件卖 / 全部卖）

**存档与开始菜单**

- 启动时出现开始菜单：继续游戏（读取最近自动存档）/ 新游戏
- 存档包含资金、天数、口碑、仓库物资、每栋建筑的等级 / 员工 / 展厅陈列

**临时机制（探索系统开放后替换）**

- 已关闭：探索系统现在负责提供物资。`GameState.placeholder_night_yield` 保留为测试开关

## 四、Phase 3 已完成（探索系统）

**昼夜衔接**

- 白天走完 → 结算面板 → 选择「休息一晚」或「外出探索」
- 探索是独立界面，不消耗游戏内时间；体力每天回满，SAN 每天只恢复 25 点

**探索流程**

- 每次出发前自动存一个「探索前存档点」，死亡后读回这里
- 出发时随机生成世界地图：十几个地形方块拼成不规则形状，最下方是出发点
- 四种地形：森林 / 沼泽 / 巨型蘑菇地 / 荒地（`data/terrains.json`）
- 进入地形后按格子移动：没走过的格子 2 体力，走过的 1 体力；每次移动有概率触发事件
- 走到格子图边缘可以从对应方向出图，经过十字形过渡区进入相邻地形（跨地形不消耗体力）
- 过渡区：入口 / 空地 / 出口 / 帐篷 / 商人位；帐篷可休息（+3 体力）或冥想（+2 SAN），商人用灰石换物资
- 灰石：探索中捡到的特殊资源，回家时由边境军队按 3 金/块低价收走
- 按 M 键随时查看世界地图（未点亮的地形显示为 ?，点亮后显示地形名）
- 事件表：低危 10 个，直接写在 `data/exploration_events.json`

**危险规则**

- 当前只做低危区：体力或 SAN 见底 → 自动回家，收获保留
- 任何时候都可以「结束探索回家」
- 高危区（体力见底丢收获、SAN 见底死亡读档）留到下一阶段

**属性与成长**

- 六项属性：体力上限、SAN 上限、采集效率、运气、议价能力、声望，各 5 级
- 升级消耗资金 + 探索物资；议价影响展厅成交与倾销价，声望影响来客频率
- 边境最深处需要六项属性全部满级才能进入
- 第一次抵达最深处会获得成就道具「边境之心」，之后再来就是高概率稀有物资

**消耗品**

- 干粮（+30 体力）、安神茶（+25 SAN）、护身符（3 次 SAN 损失减半）、幸运骰（本次运气 +25%）
- 用探索物资在「属性与打造」面板里制作，探索途中随时可以使用

## 五、素材与授权

- `art/placeholder/`：Ninja Adventure Asset Pack（CC0，可商用），当前作为占位素材
- `art/fonts/ark-pixel-12px-zh_hans.ttf`：方舟像素字体（SIL OFL 1.1），附带 `OFL.txt`
- 正式美术规格：一格 32×32 像素、1080p 基准、带斜角俯视
- 占位素材是 16×16，程序里统一按 2 倍显示，后续替换正式素材时改 `data/sprites.json` 与 `data/buildings.json` 里的贴图路径与区域即可
