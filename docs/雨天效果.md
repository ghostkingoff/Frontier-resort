# 全天降雨视觉效果

## 当前范围

雨天目前只处理画面表现，不修改顾客行为、移动速度、收入或湿滑玩法。

- `WorldWeather.today_rain` 为真时，当天全天连续降雨。
- 季节降雨概率、每日稳定抽取和 F10 强制开关继续保留。
- 清晨雾已经改为独立每日判定，不再要求昨日下雨。
- 地面积水只出现在草地、石板路和其他地面 Tile 材质中。
- 屋顶、墙面、角色和建筑表面不会生成积水。
- 本轮不包含角色踩水涟漪，也不包含雨声和水花音效。

视觉分层参考了 [2D游戏中的雨天效果 DEV LOG.02](https://www.bilibili.com/video/BV1s6rDBpEvo/) 的分层思路，项目内实现使用独立的 Canvas 雨丝层和地面噪波 Shader。

## 画面组成

### 雨丝层

雨幕由两层组成：

- `RainParticles` 使用 `CPUParticles2D` 持续发射细长斜雨，负责近景动态雨滴。
- `spring_rain.gdshader` 在世界坐标中绘制远层雨丝和薄雨雾。
- 相机移动时远层雨丝按世界坐标锚定，不会贴在屏幕上游泳。
- 粒子雨、水波粒子与雨丝速度跟随游戏速度和暂停状态。
- 夜间根据太阳和天空环境光自动降低雨丝亮度。
- 远层雨丝按世界坐标采样附近路灯和窗户局部光；近景雨粒子按视口内最强局部光整体提亮。
- 无局部光时雨滴保持低透明度，进入灯光范围后亮度和透明度同步提高。
- 当前雨点密度为上一轮完整效果的一半。

### 落地飞溅

地面 Shader 会在非积水地面生成短寿命的小型十字飞溅：

- 飞溅按世界格随机出现，不需要碰撞体。
- 只有地面材质会绘制飞溅，因此屋顶和墙面不会误出现。
- 积水内部使用水波圆环表现落雨撞击。
- 地面飞溅复用带阴影结果的局部灯光数组，受太阳、天空、路灯和窗户光共同影响。

### 地面积水

`shaders/lighting_v2/rain_ground.gdshaderinc` 使用现有无缝噪波贴图塑形：

- 水坑分布改用与雾相同的五层多尺度无缝噪波叠加。
- 噪波从 RGB 三通道取样，并使用不同尺度、旋转和权重合成密度。
- 分布完全锚定世界坐标，不使用时间漂移，因此水坑位置固定。
- 水坑纵向压缩参数为 `1.38`，使形状符合俯视地面比例。
- 高密度区域经过 `step()` 得到外层水面，更高阈值得到深水区。
- 多尺度噪波自然形成不规则边缘、断口和内部缺口，不依赖固定圆形半径。
- 每个雨天根据绝对天数生成固定的二维噪波偏移；同一天位置稳定，下一天会换成另一套水坑布局。
- 积水使用更暗的地面底色、天空冷色反射和更高光泽。
- 路灯和窗户光可以在地面积水上形成高光。
- 非积水地面同步轻微压暗，模拟雨水浸湿。

### 水波扰动

`RainRippleViewport` 使用 `CPUParticles2D` 持续发射椭圆水波环：

- 水波粒子渲染到独立的透明 `SubViewport`。
- 水波视口使用主相机相同的世界变换，因此相机放大、缩小和移动时，水波会同步变化。
- 积水 Shader 采样水波纹理，并通过邻域采样计算 UV 梯度。
- 梯度同时用于扰动倒影采样位置和增加水面高光。
- 水坑噪波密度会直接作为倒影透明度：浅水只显示少量倒影，深水反射更完整。

### 场景倒影

`RainReflectionViewport` 使用轻量 Sprite 代理复制当前可见场景：

- 不复制游戏业务节点，也不复制 TileMap 地面。
- 建筑按占地底边中心、树木和角色按脚底位置分别向下翻转。
- 建筑优先按 `wall_region_px` 的底边减去 `origin.y` 计算真实 wall 图层脚底；缺少墙区域数据时才回退到 `wall_foot_y_px`。树木和角色使用当前 Sprite 实际矩形底边。
- 每个代理逐帧同步纹理、序列帧、区域、翻转、可见性和世界位置。
- 倒影视口使用与主相机相同方向的世界变换，不再绕视口中轴线镜像。
- UI、雾、雨丝和水波 CanvasLayer 不进入倒影。
- 建筑、树木和角色倒影使用半分辨率纹理，再由积水 Shader 线性采样。

### 天空倒影

倒影视口在场景后方放置独立天空表面：

- 使用雨天天空色生成垂直渐变。
- 保留柔和的太阳方向光晕。
- 天空底图会填补建筑和树木之间的倒影空隙，避免积水出现纯黑背景。

### 水面受光

- 水面亮度由天空环境光、太阳直射光和局部灯光共同决定。
- 无光夜晚会把水面亮度和不透明度都压到很低的值，地面细节仍能看到。
- 路灯和窗户光进入水面后会同时提高水坑亮度和可见度。

### 雨天光照

降雨会把当前季节光照调整为阴雨状态：

- 降低太阳直射能量，提高阴影柔度。
- 降低天空环境能量和曝光。
- 太阳色转为灰白，天空色转为冷灰蓝。
- 后处理降低亮度、轻微去饱和并加入冷灰雨天色调。

夜间不会重新提亮整张地图；雨丝变淡，窗户和路灯仍作为主要暖色光源。

## 参数

视觉参数位于：

`data/lighting_v2/spring_weather.json`

主要字段：

- `rain_opacity` / `rain_density` / `rain_slant`：雨丝透明度、密度和倾斜。
- `rain_particle_amount`：近景粒子雨数量。
- `rain_sun_energy_factor` / `rain_sky_energy_factor`：雨天直射光和环境光倍率。
- `rain_post_brightness` / `rain_post_color`：后处理亮度和雨天色调。
- `rain_puddle_threshold` / `rain_puddle_deep_threshold`：浅水和深水噪波阈值。
- `rain_puddle_edge_softness`：无水区进入浅水区的噪波柔边宽度。
- `rain_puddle_depth_softness`：浅水区进入深水区的噪波柔边宽度。
- `rain_puddle_scale_px`：水坑噪波的世界尺度，默认 `1680`，比上一版 `420` 放大 4 倍。
- `rain_puddle_y_compression`：水坑纵向压缩。
- `rain_ripple_particle_amount` / `rain_ripple_strength`：水波粒子数量和高光强度。
- `rain_reflection_scale`：倒影纹理分辨率比例。
- `rain_reflection_strength` / `rain_ripple_uv_strength`：倒影混合和 UV 扰动强度。

## F10

F10 顶部现在提供：

- 任意绝对天数跳转，支持前一天、后一天和直接输入。
- 当前日降雨强制开关。
- 每日清晨雾强制开关。
- 降雨概率和独立雾概率分别接管。

降雨、昨日降雨和当天雾事件分别显示，不会因其中一个被强制而联动另一个。

F1 调试通道：

- `12`：积水遮罩。
- `13`：动态水波纹理。
- `14`：镜像场景倒影纹理。
