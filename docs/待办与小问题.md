# 待办与小问题清单

> 用法：把想到的问题随手写进下面的表格，不用整理。每次阶段收尾时统一清一遍，
> 由我来判断“现在改便宜”还是“以后改也没事”。

## 判断规则

## 开发约定（重要）

- **测试一律使用全新存档**：`--smoke` 跑测试前会自动清空 `user://saves_test`，每一次都是新开的档
- **玩家存档目录 `user://saves` 开发工具绝不读写**：测试写 `saves_test`，截图工具只读不写（`SaveManager.read_only`）
- 改动涉及存档结构时，除了新档，也要专门用旧档读一次，确认兼容性（例如之前「旧存档带回旧时间参数」就是这么发现的）

| 类型 | 典型例子 | 以后改的成本 | 处理方式 |
| --- | --- | --- | --- |
| 数据 / 数值 / 文案 | 建筑价格、顾客预算、事件消耗、病症数值、按钮文字 | 几乎为零（改 `data/*.json`） | 攒着，阶段收尾时一起改 |
| 界面布局 / 手感 | 面板位置、按钮大小、相机缩放、提示文字、结算排版 | 低（改一处 UI 代码） | 可拖，但最好在内容变多前定稿 |
| 规则 / 结构 | 存档内容、格子尺寸与美术规格、顾客行为方式、时间轴结构、属性体系 | 越往后越贵 | 尽早改 |

需要早改的四件事：**美术规格**、**存档结构**、**顾客行为方式**、**UI 操作范式**。

## 代码清理记录（10-04）

**修掉的真问题**

- 拆除模式按 ESC 取消失效：HUD 判断"是否处于建造状态"时漏了拆除模式，补上 `is_demolishing()`
- 底部操作提示还停留在旧控件说明，更新成现在实际的操作（B 建造含铺地/拆除、V 物资、R 屋顶、1/2/3/4 倍速、ESC 菜单…）

**性能优化**

- 客人闲逛的选点改成"缓存所有可通行地砖 + 在附近挑一个"：以前每 wander 一次要随机试 200 次格子（大地图上命中率很低），现在一次缓存、常量时间取点；顺便让闲逛都在铺好的路上，不会跑到荒地中间发呆
- 缓存与寻路脏标记复用同一处失效逻辑，铺地 / 盖楼 / 拆楼后自动重建

**清掉的无用常量**

- `DataRegistry.CELL_SIZE`、`DataRegistry.SOURCE_TILE`（格子尺寸实际由 `World.CELL` / `Building.CELL` 定义，这两个没人用）
- `Building.ROOF_SRC_RATIO` / `WALL_SCREEN_RATIO` / `SIDE_SCREEN_RATIO`（3/4 视角重写后不再使用）
- `Customer._wander_cell`（改成直接传目标后不再需要）

**删掉的死代码**

- 建筑脚本里从没被连接的三个信号（`changed` / `staff_changed` / `display_changed`）以及全部 15 处 emit
- 没人调用的函数：`can_treat`、`free_treat_slots`、`get_category_name`、`get_item`、`get_illness`、`zone_name`、`is_running`、`is_alive`、`restore`、`spend_stamina`、`spend_san`、`build_area_rect`、`buildings_of_category`、`nearest_exit`、`reset_world`
- 没用到的成员变量：`log_label`、`resume_button`、`hint_label`、`last_save_mtime`，以及 `GameState.history`（只写不读）
- 旧版探索（按深度递进）留下的 `zones` 数据与 `zone_of / zone_label / in_high_zone / ZONE_HIGH / ZONE_DEEP`
- 数据表里的无用字段：`requires_items`、`anchor_y`、`blocking`、`accent`、`mount_terrain_cost`、`deep_requires_max_attributes`、`unique`

**删掉的冗余素材**（共约 0.3 MB + 4 个角色目录）

- 未引用的贴图：`element.png`、`interior.png`、`floor.png`、`dialog_box.png`、`choice_box.png`
- 未引用的物品图标：`coin_silver.png`、`key_silver.png`
- 未引用字体 `NormalFont.ttf`（现在统一用方舟像素字体）、未引用音效 `level_up1.wav`
- 未使用的角色目录：Child、Hunter、Villager2、Villager3

**顺带优化**

- `building_reachable()` 加了缓存，客人每次生成不再对每栋建筑重跑一遍 A*；删除建筑时自动失效
- 只有医院会逐帧 `_process`（以前所有建筑都在跑空帧）
- 界面改名：`start_menu` → `pause_menu`、`_show_start_menu()` → `_hide_pause_menu()`（它现在其实是暂停菜单）
- 标题界面在没有任何存档时，「读取存档」按钮直接置灰
- 倾销面板拒绝出售价值为 0 的物品（成就道具「边境之心」）
- 退出时停止并释放音乐播放器

**已知的无害告警**：退出时 Godot 会打印一条 `resources still in use`（标题 BGM 用的 ogg）。这是引擎在退出流程里对 ogg 播放对象的处理，只在控制台可见，不影响游戏；换成 wav 或正式音乐资源时会自然消失。

## 已实现的画面光照

- 关键帧写在 `data/lighting.json`，改颜色不用碰代码
