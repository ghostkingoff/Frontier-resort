# 雪天视觉效果

## 当前实现

雪天由独立 `snow` 天气事件驱动，可在全天任意时段开始，并像雨、雾、云一样使用事件包络淡入淡出。

当前画面包含三层：

1. `GPUParticles2D` 飘雪。
2. 世界坐标噪波生成的地面积雪遮罩。
3. 建筑屋顶、墙壁朝上区域和松树顶部的积雪覆盖。

## 飘雪粒子

- 雪花使用程序生成的 `3×3` 像素雪花图集。
- `CanvasItemMaterial` 启用粒子图集动画和 Add 混合。
- `ParticleProcessMaterial.anim_offset` 在 `0–1` 内随机，`anim_speed` 为 `0`，使每片雪固定随机一个图集帧。
- 雪花层跟随相机世界变换，粒子发射中心锚定相机所在世界坐标；镜头移动时已有雪花留在原地，只在相机周围持续补充新雪。
- 发射区域按相机缩放换算成世界尺寸，不再固定在屏幕中心；生命周期随机、Alpha Curve 和 Scale Curve 继续平滑出生与消失。
- 粒子的世界尺寸、初速度和重力会按相机缩放反向补偿，因此放大或缩小镜头时，雪花的屏幕大小和下落节奏保持上一版观感。
- 粒子速度跟随游戏倍速，暂停时冻结。
- 夜间会使用更暗的冷色雪花，白天则接近暖白。

## 地面积雪

`snow_cover.gdshaderinc` 使用专用无缝覆盖图
`art/generated/lighting_v2/snow_coverage.png`，不再复用雾的云团纹理：

- 低频域扭曲分形形成大块不规则积雪，细碎通道制造断口和离散小岛。
- 窄 `smoothstep` 阈值控制积雪覆盖率，保持硬像素边缘而不是圆形软团。
- 地面与屋顶遮罩统一按俯视 45° 投影做纵向压缩，当前压缩系数为 `√2`。
- 坐标按像素网格量化，保持像素画边缘。
- 雪色在地面材质受光计算前混入，因此会继续受太阳、云影、路灯和窗户光影响。
- 雪停后地面积雪不会立即消失，而是按 `snow_ground_melt_speed` 缓慢融化。

## 建筑与物体积雪

- 建筑屋顶使用建筑自身 UV 和独立的 1024 像素采样尺度，避免世界噪波把屋顶横切成矩形。
- 屋顶按约一半的破碎斑块覆盖，保留明显的原屋顶颜色，不会整片涂白。
- 墙体只覆盖法线朝上的局部区域。
- 松树使用 512 像素局部采样尺度，并通过法线朝向控制顶部积雪。
- 角色和室内层不应用屋顶积雪材质。

## 大小档视觉

雪读取 `size_visual_profiles.snow`。飘雪粒子恢复上一版观感；地面积雪的小、中档比上一版下调，大雪上限则进一步扩大：

- 小雪：保留上一版飘雪粒子，积雪形成速度和地表覆盖降低，积雪融化更快。
- 中雪：保留上一版飘雪粒子，积雪覆盖低于上一轮，但高于小雪。
- 大雪：使用上一版大雪粒子，并显著提高积雪速度和覆盖尺度；遮罩阈值大幅降低，地面只留下少量草地断口。

积雪档位同时影响飘雪粒子、降雪时的天空/曝光强度、地面积雪、屋顶积雪、松树积雪和积雪消融速度。

## 主要参数

位于 `data/lighting_v2/spring_weather.json`：

- `size_visual_profiles.snow`：小、中、大雪的粒子、积雪与消融倍率。
- `snow_chance`：每日自动雪事件概率。
- `snow_particle_amount` / `snow_particle_lifetime`：飘雪数量与寿命。
- `snow_fall_speed` / `snow_wind_px_per_second`：下落速度和横向风速。
- `snow_color` / `snow_night_color`：昼夜雪花颜色。
- `snow_ground_growth_speed` / `snow_ground_melt_speed`：积雪增长和消融速度。
- `snow_cover_threshold` / `snow_cover_softness`：积雪覆盖率和边缘柔和度。
- `snow_cover_scale_px`：积雪噪波的世界尺度。
- `snow_cover_pixel_size_px`：积雪边缘的像素化尺寸。
- `snow_cover_y_compression`：积雪遮罩的俯视角纵向压缩系数。
- `snow_cover_color`：雪层反照率颜色。
- `snow_object_coverage_scale`：建筑和松树积雪相对地面的覆盖率。

## F10

F10 天气区提供：

- 今日自动雪事件开关。
- 每日自动雪事件概率。
- 小、中、大雪事件直接触发。
- 雪事件持续时间、当前剩余时间和事件包络状态。
- 清除雪事件。

真实窗口验证可使用：

```powershell
godot --path "E:\godot\模拟经营类(1)" -- --runtime-main-shot --hold-hour=12 --game-day=105 --hold-snow=1 --hide-labels
```

三档视觉可直接使用 `--hold-snow=small`、`--hold-snow=medium` 或
`--hold-snow=large`。
