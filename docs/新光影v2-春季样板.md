# 新光影 v2：春季平地样板

## 当前范围

新光照已经接入正式主关卡；独立样板仍保留，用于快速比较单项效果。

- 正式主场景使用春季、夏季、秋季、冬季四套连续太阳环境。
- 暂不处理水体、高度差和场景季节换装。
- 已接入全天连续降雨、独立清晨雾和噪声深度视觉雾；雾在 30 游戏分钟内淡入和淡出。
- 画面仍使用 2D 像素 Sprite。
- 实际光源和遮挡由隐藏的 Forward+ 3D 代理世界生成。
- 目标平台为桌面端。
- 正式素材来自 `E:\素材\aseprite`。
- 基础度假屋、小商店、小型超市、松树和路灯已接入正式分层光照素材；
  其余建筑和部分角色仍保留占位素材。

主场景已经停用旧的 `CanvasModulate + NextLightingSystem` 并行光照。
不可行走 `草地`、可行走 `修剪草坪`、石板路和松树已经替换为正式素材。

## 启动方式

直接运行：

```powershell
godot --path "E:\godot\模拟经营类(1)" res://scenes/lighting_lab.tscn
```

运行正式主场景：

```powershell
godot --path "E:\godot\模拟经营类(1)"
```

操作：

- `←` / `→`：每次调整 15 分钟。
- `1`：07:30 清晨。
- `2`：12:00 正午。
- `3`：17:30 傍晚。
- `4`：21:30 夜晚。
- `Space`：暂停或继续自动时间。
- `F1`：依次查看最终画面、颜色、法线、高光、Occlusion、太阳阴影、路灯合并阴影、四页三色路灯通道、20×20 区域网格、积水遮罩、水波纹理和倒影纹理。
- `F10`：打开开发事件控制台，可接管天气及各玩法模块的高层概率。
- F10 天气区提供 06:00 / 06:15 / 06:30 / 07:00 / 08:30 / 08:45 / 09:00 雾时段预览。
- F10 同时提供随当前季节变化的日出、上午、太阳最高、下午、日落、深夜预览，点击后停在目标时刻。

主场景中也可以按 `F1` 切换地面和建筑表面的调试通道。
开发事件控制台是 `F10`，打开期间会锁定玩家和相机的键盘移动，并阻挡地图鼠标操作。

## 已实现

- 桌面端 Forward+ 渲染器。
- 世界层启用 HDR 2D、高光肩部压缩和轻量 Bloom。
- 全屏显示提亮使用“常规 RGB 伽马 + 保色相亮度伽马”混合，不再统一降低饱和度，避免无雾画面出现灰罩。
- 主地图地面拆成草地、石板路和占位地形三个独立图层。
- 草地专用大面积噪波阴影：只作用于普通草地和修剪草坪，每天随机化偏移、旋转与尺度，并以 `1.6–3.2px/s` 在世界坐标中漂移；当前阴影强度 `0.20`、密度阈值 `0.40`。石板路不采样这层阴影。
- 2D 地表、建筑、树和角色表面材质。
- 颜色、法线、高光、Occlusion 四通道合成。
- 太阳完整方向变化。
- 隐藏 3D 低模阴影。
- 清晨和傍晚的长阴影。
- 月光关闭动态阴影，只保留偏蓝环境光。
- 路灯真实遮挡光照和灯头光晕。
- 春季天空色和环境色随小时连续插值。
- 每日降雨与清晨雾按日期独立抽取，并分别保留在 F10 控制台中。
- 新增独立 `SpringFog` 层，不混入调色 Shader。
- 雾密度贴图在 RGB 三通道保存三组独立无缝噪声，深度贴图同样保存多组独立伪深度。
- 雾使用五层不同尺度、旋转和通道的噪声，并叠加错速 UV 漂移、低频涡流和缓慢的密度呼吸；伪深度贴图控制局部厚度和空缺。
- 雾的基础时间速度提升为 `2.0×`，并继续乘以 `GameClock.time_scale()`，随 `1× / 2× / 4× / 64×` 游戏倍速变化；游戏暂停或进入结算时冻结。无光时雾亮度降为 `0.09` 的暗雾。太阳出现后通过 30 游戏分钟平滑接入提亮、暖色和蒸发，并按当前季节日出时间过渡；强光仍会在太阳一侧形成柔和的暖色散射。
- 雨天使用粒子近景雨丝和 Shader 远层雨幕；地面通过双层 `step()` 噪波生成积水，独立水波视口驱动物体倒影的 UV 扰动。倒影视口共享主世界并补入天空底图，积水只写入地面材质。
- 天空云层阴影独立于雾事件：云影噪声按世界坐标沿太阳方向拉伸，并缓慢漂移、变宽、收窄和分叉；只压暗场景太阳受光，不提供风变量。
- 季节日历底层已建立：4 季 × 30 天、120 天一年，HUD 显示年份、季节和季内天数。四季日出、太阳高度、颜色、环境光、云量、阴影柔度和天气光感由季节参数连续驱动，详见 `docs/季节光照与成都太阳参数.md`。当前雾/云/降雨触发暂不随季节变化。
- 建筑 3D 阴影代理按模型真实包络导出并统一使用 `32×`，不再按建筑逻辑占地拉伸；详细规范见 `docs/3D阴影代理制作规范.md`。
- 建筑阴影只参与地面、建筑和角色受光。假设雾层高度高于建筑高度，因此建筑阴影不再影响雾。
- 雾层不读取天空云影、建筑阴影、天空环境色或画面亮度，只由太阳颜色、太阳能量和日出过渡控制。
- 雾密度图 `1024×1024`、深度图 `512×512`，均为程序生成的无缝灰度贴图。
- 雾层使用世界坐标锚定；相机平移时不会跟着屏幕游泳。
- 06:00–06:30 淡入，06:30–08:30 满强度，08:30–09:00 淡出。
- 夜间天空环境能量降到约 `0.04`，夜间曝光为 `0.20`，低于白天的 `0.78`。
- 深夜以近黑绿背景为主，不叠加整屏蓝色；地形和建筑轮廓仍可辨认，窗户与路灯保留暖色对比。
- 太阳颜色由高度角驱动：日出和日落最红，正午最白；直射能量在日间由弱到强再转弱。
- 太阳出现和消失时间由当前季节的日出、日落参数决定；两端保留低能量暖红，夜间完全熄灭。
- 建筑墙面在背向太阳时整面进入阴影，并排除建筑自身地面投影对墙、屋顶的自遮蔽。
- 玩家角色复用整面朝向门控：脚点与局部灯齐平时开始进入阴影，脚点继续向下 48 像素后完全阴影；脚点在灯下方时正常受光，每盏局部灯独立计算。
- 玩家材质不采样自身投下的太阳/灯光阴影，阴影代理脚点按 1 像素对齐；法线、Specular 和 Occlusion 直接复用 `Sprite2D` 的当前帧 UV，避免二次偏移到相邻帧或透明区域。法线按每个序列帧独立导入并使用 nearest 过滤，消除向左、向上移动时的缺块与串色闪烁。`star2a` 已从新目录重新导入并重排 Base/Normal/Specular/Occlusion。
- 角色太阳地面影改用 `Star2A_3DShadowProxy.blend` 导出的 3D 角色代理，并按俯视朝向旋转 0°、180°、-90°、90°。角色拥有独立的玩家太阳阴影通道，逐帧跟随相机刷新后叠加到全部地面材质，保证整个地图范围内持续更新；通道内另有一个低矮的脚部接触投影体，避免低太阳角度下拉长影与脚底断开。建筑、树木和路灯继续使用公共 3D 阴影通道。
- 建筑墙面把“仅建筑”的独立太阳阴影与当前 wall 像素做屏幕空间叠加，叠加区域的下边界固定为 wall 底边。墙面不会新建角色剪影：低太阳产生的长地面影按太阳高度比例压入 3D 代理的 `44px` 高度，顶部最后 `15%` 渐隐；剪切量根据太阳方向与墙面轴线的夹角实时计算，并以 `√太阳拉伸倍率` 作为横向基准，避免高度压缩与剪切完全耦合。墙脚高度为零时采样坐标不变。仅 `wall` 材质启用。
- 窗户矩形灯头光位于普通室外层，角色走到建筑前方时会覆盖窗光；路灯灯头光使用更高的前景层，始终保持覆盖角色。
- 太阳与路灯阴影图模糊略微提高，使角色投在地面的影子边缘更柔和。
- 墙面由整体背光转为整体受光时使用连续 `smoothstep` 过渡，默认在约 11:30–14:00 之间逐级变化。
- `F10` 开发事件控制台统一接管天气、游客、经营、疾病和探索的高层概率。
- `F10` 顶部新增实时光照调参区，可调整窗头/路灯头透明度与亮度、两类地块光亮度、半径、衰减距离以及路灯椭圆纵向比例。窗头参数每帧写入发光材质，滑杆修改会立即生效。
- “打印并复制当前光照数据”会同时显示 JSON、复制到剪贴板并写入 `.tmp/lighting_tuning.json`。
- 探索风险、奖励提供整体概率倍率，避免逐条维护大量子概率。
- 静态阴影只在相机、时间或代理发生变化时重新渲染。
- 玩家和场上游客都会生成动态低模阴影。
- 正式树木装饰会自动注册可见材质；阴影使用树冠透明剪影，而不是圆锥占位体。
- 室内使用独立的暖色房间光，切断室外太阳对室内贴图的主要影响。
- 夜晚窗户根据门户标记发出方形柔光，不按建筑中心猜测位置。
- 窗户本体保持矩形灯头光，灯头透明度为 `15%`、亮度为 `50%`；窗下照明作为无阴影虚拟局部光源并入路灯同一光数组，复用颜色、能量、高度和法线受光。局部光中心与窗头重合，选灯半径为 `21` 像素，视觉衰减半径为 `52.5` 像素，能量比例为路灯局部光能量的 `1%`。窗户地面光只在所在建筑 wall 脚底以下显示，脚线上下使用 `10px` 平滑过渡。
- 基础度假屋新增 `ground` 地形装饰层，使用与地块相同的 `spring_tile` 光照材质；只在屋顶视图显示，屋内和地面透视模式隐藏。
- 窗户地块光使用线性衰减，亮度为路灯局部光能量系数的 `9%`。
- 路灯地块光使用翻倍衰减距离和 `4` 次方衰减；窗户地块光除 wall 脚线过渡外继续使用现有径向衰减参数。路灯头光亮度为 18%、透明度为 12%，渲染在灯头贴图后方。
- 路灯代理在太阳阴影通道保持 `layer 1`，确保太阳阴影正常；仅在路灯阴影通道使用独立图层。每盏路灯只排除自身路灯代理，其他建筑、树木、角色和其他路灯代理均可遮挡它。
- 路灯新代理统一使用真实模型包络和 `32×` 缩放，旧版 `shadow_proxy_height_scale=0.54` 已恢复为 `1.0`，避免太阳影被压成短线。
- 路灯同时设置 `light_cull_mask` 与 `shadow_caster_mask`，确保自身代理既不接收自身光，也不会把自己的阴影投回光池；不再使用灯脚圆心补丁。
- 路灯地块中心位于某建筑 wall 脚线以上时，该建筑 wall 的局部光被底模遮挡；中心低于脚线后平滑恢复墙身受光。roof 材质无条件关闭所有局部路灯照明。
- 窗户地面光携带所属建筑令牌：本建筑的窗光可以绕过路灯前后门控照亮自己的 wall，其他建筑窗光不会串墙。
- 路灯地块光在 45° 俯视下保持当前横向半径，纵向压缩到横轴的 `1/√2`；椭圆同时作用于径向衰减和地面法线受光方向。窗户地块光保持圆形。
- 白天窗光会根据太阳方向投入室内，并使用 `canwalk` 遮罩避开家具占据区域。
- 最终色彩分级和暗角在独立后期阶段处理。
- 地图按 20×20 地块划分光照区域，按灯光影响范围与区域相交来选灯。
- 每个区域最多选三盏投影灯，并使用区域级与全局级两层滞回避免阴影突然开关。
- 各区域候选灯合并后，使用四页 RGB 三通道全局阴影图集，最多十二盏同时投影。
- 阴影始终使用全局阴影图，不会在区域边界被截断。
- 其余局部灯保持发光，但跳过阴影采样；当前最多同时处理 32 盏相关局部灯。
- `F1` 的区域网格视图可以直接检查 20×20 划分。

## 当前已知限制

- 墙面投影仍使用屏幕空间高度偏移近似，还不是独立的立面阴影相机；当前已排除自身投影并加入整面背光判定。
- 世界内建筑名和玩家名仍在后期色彩处理前，尚未迁移到与 HUD 相同的 UI 层。
- 局部照明最多同时处理 32 盏，更多灯需要下一步做屏幕分块光源列表。
- 当前雾层是二维噪声深度近似，不理解建筑、树冠和真实地形高度；深度图暂时只提供风格化体积感。
- 树影已经使用透明树冠剪影，但极低太阳角度下仍可能出现偏细的枝条阴影。
